# Calendario2026

Sistema de calendário e organização de postagens para redes sociais.

O projeto foi desenvolvido para facilitar o planejamento semanal e mensal de conteúdos, permitindo organizar horários de publicação para plataformas como Instagram, TikTok, YouTube e outras redes sociais.

O sistema permite:

* Selecionar dias específicos do calendário
* Definir até 3 horários de postagem por dia
* Organizar conteúdos programados
* Marcar publicações já realizadas
* Evitar perda de organização nas postagens
* Melhorar o controle do planejamento de conteúdo

A ferramenta foi criada com foco em produtividade e gestão de conteúdo digital, ajudando criadores e equipes a manterem consistência nas publicações.
